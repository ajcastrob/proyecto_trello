# TaskApp

Clon de Trello con Django 6.1 y Tailwind. Tableros, listas y tareas.

Demo: https://proyecto-trello-64iu.onrender.com

## Local

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Abre http://127.0.0.1:8000
